# explainable-churn-analytics

A visual analytics system that predicts customer churn and explains the predictions using SHAP.

## Current features

- Customer churn prediction
- Model performance evaluation
- Global and customer-level SHAP explanations
- What-if simulations
- Interactive customer-risk visualization
- Customer-profile flow visualization

## Dataset

IBM Telco Customer Churn dataset containing 7,043 customers and 21 columns.

## Model

A balanced logistic regression model with preprocessing for numerical and categorical features.

## Results

- ROC-AUC: 0.841
- Recall: 0.783
- F1 score: 0.613

## Technologies

Python, pandas, scikit-learn, SHAP and Plotly.
